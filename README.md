# 📊 Estatística Aplicada à Análise de Dados com Python

**Projeto prático focado na aplicação de conceitos estatísticos para análise e modelagem de dados.**

##  Objetivo do Projeto

Aplicar conceitos fundamentais de Estatística e Modelagem Preditiva utilizando Python, simulando cenários próximos ao contexto real de análise de dados.

##  O que foi explorado

- Regressão Linear Simples  
- Regressão com Ruído Estatístico  
- Correlação e Correlação de Pearson  
- Divisão de Dados em Treino e Teste  
- Avaliação com Erro Quadrático Médio (MSE)  

##  Stack Utilizada
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-Learn
- SciPy
<hr>

## 📈 Modelagem 1 — Regressão Linear Simples

###  Problema

Identificar a relação entre variável independente (X) e variável dependente (Y).

###  Solução Aplicada

* Construção do modelo com `LinearRegression`
* Extração de coeficiente angular e intercepto
* Realização de previsões
* Visualização da reta de regressão

###  Insight

O modelo conseguiu representar perfeitamente a relação linear entre as variáveis, evidenciando a aplicação do método dos mínimos quadrados.
<hr>

## 📈 Modelagem 2 — Regressão com Dados Dispersos

## Problema

Simular dados reais contendo variabilidade e ruído.

## Solução Aplicada

- Geração de dados aleatórios com ruído  
- Ajuste do modelo aos dados simulados  
- Análise do impacto do ruído nos coeficientes  

### Insight

Mesmo com variabilidade nos dados, o modelo foi capaz de estimar corretamente a tendência central da relação.
<hr>


## 📈 Análise 3 — Correlação Negativa

###  Problema

Avaliar a relação entre temperatura e vendas de agasalhos.

###  Solução Aplicada

* Criação de DataFrame com Pandas
* Cálculo da matriz de correlação
* Aplicação do teste de Correlação de Pearson
* Interpretação do p-valor

###  Insight

Foi identificada uma forte correlação negativa:
quanto maior a temperatura, menor o volume de vendas.

---

## 📈 Modelagem 4 — Treino e Teste

###  Problema

Simular cenário real de Machine Learning com validação do modelo.

###  Solução Aplicada

* Divisão dos dados com `train_test_split`
* Treinamento do modelo supervisionado
* Avaliação com Erro Quadrático Médio (MSE)

###  Insight

O uso de validação permite medir a capacidade preditiva do modelo e evitar overfitting.
